# 智学图谱

## 项目简介

智学图谱是一款纯前端的考试与复习管理工具，帮助学生在备考期间高效管理考试日程、追踪复习任务进度，并通过可视化图表直观掌握复习完成情况。数据完全存储在浏览器本地（localStorage），无需后端服务、无需注册账号，打开即用。

## 功能清单

- **考试管理**：新增、编辑、删除考试，支持考试名称、日期、备注，自动按日期排序
- **复习任务管理**：为每场考试添加复习任务，支持完成态切换、编辑、删除，任务必须关联考试
- **统计图表**：环形进度图展示单场考试任务完成率，柱状图展示近期考试任务量
- **即将考试区域**：最近 3 场考试大卡片展示，7 天内紧迫高亮
- **数据导入导出**：一键导出 JSON 快照，支持导入恢复，含格式校验与原子性回滚
- **演示辅助**：载入示例数据、一键清空数据，方便评审体验
- **响应式适配**：768px 断点，移动端与桌面端均可用
- **404 路由与错误处理**：未知路径兜底页，全局错误捕获

## 本地启动

```bash
# 安装依赖
npm install

# 启动开发服务器（默认端口 5173）
npm run dev
```

浏览器访问 `http://localhost:5173` 即可使用。

## 构建命令

```bash
# 构建生产产物到 dist/
npm run build

# 本地预览构建产物
npm run preview

# 运行自检脚本（需设置 DEMO_URL 和 REPO_URL 环境变量）
npm run self-check
```
